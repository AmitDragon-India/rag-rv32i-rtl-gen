## Wiring Rules

1. IF stage has internal imem — no external imem ports on rv32i_top
2. Data memory is a logic array inside rv32i_top — dmem_* wires connect to mem_stage ports
3. alu_control takes opcode/funct3/funct7 from IF/ID register bits directly
4. regfile rs1_addr = if_id_instr[19:15], rs2_addr = if_id_instr[24:20]
5. wb_data feeds back to ex_stage.wb_data for MEM/WB forwarding
6. ex_mem_alu_result feeds back to ex_stage.ex_mem_alu_result for EX/MEM forwarding
7. pc_next = ex_redirect_en ? ex_redirect_pc : if_pc_plus4
8. stall_pc connects to if_stage.stall
9. flush_if_id connects to if_stage.flush AND IF/ID register flush
10. flush_id_ex flushes both ID/EX and EX/MEM registers
11. EX/MEM register takes reg_write/mem_read/mem_write/wb_sel from EX stage outputs
    NOT directly from ID/EX register — EX stage passes them through

## Signal Flow

```
IF stage
  internal imem[pc] -> instr
  -> if_id_instr, if_id_pc, if_id_pc_plus4 (via IF/ID register)

alu_control
  <- if_id_instr[6:0]   (opcode)
  <- if_id_instr[14:12] (funct3)
  <- if_id_instr[31:25] (funct7)
  -> alu_op_wire

ID stage
  <- if_id_instr, if_id_pc, if_id_pc_plus4
  <- regfile (rs1_data, rs2_data)
  <- alu_op_wire
  -> id_* signals (via ID/EX register)

ID/EX register
  captures ID stage outputs each cycle
  flush_id_ex zeros all control signals
  stall holds current values

Forwarding unit
  <- id_ex_rs1, id_ex_rs2, id_ex_alu_srcB
  <- ex_mem_reg_write, ex_mem_rd
  <- mem_wb_reg_write, mem_wb_rd
  -> forward_a, forward_b, forward_s

EX stage
  <- id_ex_* signals
  <- forward_a, forward_b, forward_s
  <- ex_mem_alu_result (EX/MEM forwarding feedback)
  <- wb_data (MEM/WB forwarding feedback)
  -> ex_alu_result, ex_store_data_fwd, ex_pc_plus4_out
  -> ex_redirect_en, ex_redirect_pc, ex_branch_taken
  -> ex_reg_write_out, ex_rd_out, ex_wb_sel_out
  -> ex_mem_read_out, ex_mem_write_out

Hazard unit
  <- if_id_instr (full 32-bit — extracts rs1[19:15], rs2[24:20] internally)
  <- id_ex_rd, id_ex_mem_read
  <- ex_redirect_en (from EX stage)
  -> stall_pc, stall_if_id, flush_if_id, flush_id_ex

EX/MEM register
  captures EX stage pass-through outputs each cycle
  flush_id_ex zeros all control signals
  NOTE: takes reg_write, mem_read, mem_write, wb_sel from EX stage outputs
        NOT directly from ID/EX register

MEM stage
  <- ex_mem_alu_result  (dmem address)
  <- ex_mem_store_data  (store write data — already forwarded)
  <- ex_mem_mem_read, ex_mem_mem_write, ex_mem_funct3, ex_mem_wb_sel
  <- ex_mem_pc_plus4, ex_mem_imm_u (pass-through values)
  <- ex_mem_reg_write, ex_mem_rd
  <- dmem_rdata (from data memory array)
  -> dmem_addr, dmem_wdata, dmem_byte_en, dmem_we, dmem_re
  -> mem_rdata_out (sign/zero extended load data)
  -> mem_alu_result_out, mem_pc_plus4_out, mem_imm_u_out
  -> mem_wb_sel_out, mem_reg_write_out, mem_rd_out

MEM/WB register
  captures MEM stage outputs each cycle

WB stage
  <- mem_wb_alu_result, mem_wb_mem_rdata
  <- mem_wb_pc_plus4, mem_wb_imm_u
  <- mem_wb_wb_sel
  -> wb_data

Regfile write port
  <- wb_data (from WB stage)
  <- mem_wb_rd
  <- mem_wb_reg_write

Feedback paths
  wb_data          -> ex_stage.wb_data          (MEM/WB forwarding)
  ex_mem_alu_result -> ex_stage.ex_mem_alu_result (EX/MEM forwarding)
```

### 4-input Mux

```systemverilog
always_comb begin
    unique case (sel)
        2'b00: y = a;
        2'b01: y = b;
        2'b10: y = c;
        default: y = '0;
    endcase
end
```

Notes:
- Use `unique case` for decoder and mux logic to enable tool warnings on overlap
- Always include a `default` to cover undefined states
